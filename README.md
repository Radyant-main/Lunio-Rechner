# Lunio-Rechner

Dieses Repository enthält den Lunio-Rechner als statische Webseite für GitHub Pages.

## Veröffentlichung auf GitHub Pages

1. Code nach GitHub pushen.
2. In GitHub: **Settings → Pages**.
3. Unter **Build and deployment** bei **Source** wählen:
   - **Deploy from a branch**
   - Branch: `main` (oder die gewünschte Branch)
   - Folder: `/ (root)`
4. Speichern und auf das Deployment warten.

Danach ist der Rechner unter der GitHub-Pages-URL verfügbar.
